# Tide — 让 DSH 记住聊过的事

[English](./README.en.md)

你在一个聊天里说过「我喝咖啡不加糖」，也聊过「上周去杭州出差」。开启跨会话记忆后，你可以在另一个聊天里问起这些事。机器人记下来的事实和经历，可以在 Tide 的「记忆浏览」里查看。

- **自动记事。** Tide 从聊天里挑出值得保留的内容，例如饮食偏好、待办和发生过的事。它使用该会话选的模型来整理记忆。
- **记忆可以纠正。** 记错了能改，不要的能删，删了还能查到原因。回答时，Tide 只带当前有效的值和可能用得上的经历。
- **群里按需接话。** 开启群聊初筛后，Tide 会看机器人有没有被点名、当前在聊什么。它可以略过闲聊，遇到判断不准的消息也可能请模型判断。机器人还可以主动选择不回。
- **记住聊天规矩。** 可以给机器人定规矩，比如「群里回答简短一点」。已保存且适用于当前聊天的规矩，会进入机器人回答时遵循的说明。

设置项在插件详情页的「Tide」里改，保存后五秒内生效，不用重启。

## 安装后怎么试

1. 在 DSH 的插件管理器中安装 `dsh-chat-tide`。确认当前配置（profile）的 `package.json` 里 `dsh.profile.bundles` 包含 `dsh-chat-tide`；少了这一步会「装了但不加载」。
2. 打开插件详情页，在「作用域」里选它管哪些聊天。用 QQBot 时选 `follow`，会跟着 QQBot 的会话，并覆盖同一工作区的本地聊天；只用本地聊天就指定工作区或会话。
3. 在「开关」里确认「上下文注入」开着，让机器人回答时用上记下来的内容。
4. 先挑一个私聊或本地聊天，告诉机器人一件具体的事，等这轮回复结束，在「记忆浏览」里找到它，再问机器人能不能想起来。

这些开关也可以在 profile 的插件配置里写，效果一样：

```yaml
scope:
  mode: follow
features:
  contextInject: true
  routing: false
```

想让 Tide 判断群里哪些消息值得接话，再把 `features.routing` 打开。

## 跨会话记忆

打开「统一会话」（`context.unifySessions`），机器人回答时就会用到其他聊天里的记忆。想试，就用同一个 QQ 账号，在一处说件具体的事，再到另一处问起它。

「群聊屏蔽私聊来源」默认开着，让群聊里自动挑记忆时跳过私聊内容。注意这是挑选的那一层：机器人主动搜索记忆时仍会查到整个库。

## 兼容性和数据位置

| 项目 | 要求 |
| --- | --- |
| DSH | `>=0.2.2-rc.1 <0.3.0` |
| Node.js | `>=22.5` |
| QQBot | QQ 聊天和群聊接话需要 QQ 适配器，已测试 `@tencent-connect/dsh-qqbot@0.5.5`。本地聊天可以单独使用。 |

记忆默认保存在 `~/.dsh/tide/memory.db`，改坏了可以直接用设置页里的编辑和删除修，不必动文件。首次使用会下载约 25–30 MB 的本地模型，用来判断话题和记忆的相关性，模型默认保存在 `~/.dsh/tide/models`，重装不会丢。
