# Tide — 让 DSH 记住聊过的事

[English](./README.en.md)

Tide（`dsh-chat-tide`）是 DeepSeek Harness（DSH）的聊天记忆插件。它能在不同聊天里回忆你说过的事，也能让 QQ 群里的机器人按需接话。支持本地聊天；QQ 群功能需要 QQBot。

- **自动记事**：从对话里挑出值得留下的偏好、待办和经历，用该会话已选的模型整理，不另配模型。
- **记忆可改可删**：事实改错能修、能删，删除留审计。回答时只带当前有效的值和可能相关的经历。
- **按需接话**：群消息先过闸门，不该接的在模型调用之前丢掉；判断不准时交模型裁决，机器人也可以选择整轮不说话。
- **规矩常驻**：群规、红线这类内容进系统提示，不占对话位置，也不会被压缩掉。
- **跨会话**：可选让不同聊天共用一份记忆；群聊里自动挑记忆时默认跳过私聊来源。
