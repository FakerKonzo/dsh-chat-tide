# 安装与使用指南

Tide 是 DSH 的聊天记忆插件。这份文档讲怎么装、怎么配、怎么验证它在工作，以及出问题时先看哪里。

- 包名 `dsh-chat-tide`，插件行 id `tide`
- 数据在 `~/.dsh/tide/memory.db`，向量模型在 `~/.dsh/tide/models`
- 设置项在插件详情页的「Tide」里，保存后五秒内生效，不用重启

## 安装

1. 在 DSH 插件管理器中点「添加插件」，输入 `dsh-chat-tide` 并安装。
2. 安装完成后点「立即启用」。DSH 会自动把 Tide 加到当前配置中。如果界面提示重启 DSH，按提示操作即可。
3. 随包配置的作用域是 `follow`：**只覆盖 QQ 会话**（群和私聊）；记忆注入和群聊初筛默认都开着，装了就能用。想让本地会话也归它管，把「作用域」改成 `workspace`（填工作区路径，那里的 QQ 和本地会话都算），或者用 `sessions` 点名具体会话。

首次使用会下载一个约 25–30 MB 的本地向量模型，用来判断话题和记忆的相关性。下载失败会明确报错，不会在宿主进程里偷偷重试。

## 设置页长什么样

从上到下四块：

**日常**——在哪些聊天里使用、自动记事、回答前自动找记忆、群里按需接话。选到「指定工作区」才出现路径输入，选到「指定会话」才出现会话选择器。打开「回答前自动找记忆」后才会出现「也用其他聊天的记忆」，再往下是「群聊自动找记忆时跳过私聊内容」。

**机器人**——谁可以给机器人定规矩（右侧会显示当前生效的 openid 和来源），以及机器人怎么说话（跟随工作区文档，或者用你写的那段）。

**更多设置**——折叠起来，放安静时段、每天最多尝试主动接话几次、两次试探的间隔。

**高级参数**——默认整块隐藏，页面底部有「显示高级参数」。里面是阈值、字符预算和诊断开关，调之前先想清楚。

「自动记事」关掉后，正常抽取和漏抽补记都会停，原始聊天记录仍然保留；三个细分选项会变灰，重新打开时沿用原来的选择。

## 试用

1. 先挑一个私聊或本地聊天。
2. 说一件具体的事，例如「我喝咖啡不加糖」。
3. 等这轮回复结束。
4. 在「记忆浏览」里找到刚才那条事实。
5. 再问机器人「我喝咖啡加糖吗」，看它答得对不对。

跨会话记忆：打开「也用其他聊天的记忆」，在一处说件事，再到另一处问起它。用同一个 QQ 账号最容易验证。

## 导出与备份

设置页底部有「导出与备份」：

**导出配置**——下载一份 JSON，含设置、人设和规矩。可以带到另一个环境，把那段 JSON 贴回「导入」框，先看预览（会列出哪些设置会变、哪些规矩是新增的），确认后才写进去。导入只碰设置和规矩，不动记忆库。

**备份数据库**——下载整库快照。用的是 SQLite 的一致性备份，会把还没合并进主文件的 WAL 内容一起带上；生成后会只读打开校验完整性并核对条数，对得上才交给你。恢复时退出 DSH，用备份文件替换 `~/.dsh/tide/memory.db` 即可。

运行中直接复制 `memory.db` 是不够的：最近的写入可能还在 `-wal` 文件里。要么用上面这个备份，要么退出 DSH 再复制。

## 出问题先看哪

- **没记住任何东西**：确认作用域选对、「自动记事」和写入开关都开着；再看注入日志有没有记录。
- **群里有消息但不回**：打开「群里按需接话」才有接茬判定；机器人可以选择整轮不输出，这是正常行为。
- **旧值还在**：事实改过之后旧值不该再出现；如果还看得到，先确认插件是 0.5.3 以上。
- **数据库状态**：插件目录里跑 `node scripts/doctor.mjs`，它会报数据库完整性、向量维度、外键和索引对齐。
- **某个会话打不开，报 `system/message does not match an open turn and step`**：这是 0.6.3 及更早版本留下的坏日志。先关掉 DSH，再跑 `node scripts/repair-session-log.mjs --scan "%USERPROFILE%\.dsh\sessions" --write`；不加 `--write` 只体检。

## 数据与备份

记忆是单个 SQLite 文件。删除一条事实或经历会留审计行，仍可用设置页或只读查询查回原因。

开发和排查的内部细节见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

### 拒答和会话修复

启用静默保护时，Tide 会等当前一步结束再发送正文。如果这一步调用了 `run_code`，Tide 会保留工具调用，略过同一步的过渡文字。正常回答在后续步骤发送，经工具决定拒答时，群里看不到这段过渡文字。

会话修复工具会把结果写到临时文件，用 DSH 的 V4 会话读取器完整回放，成功后才替换原文件。独立运行需要与 DSH 配套的 `@deepseek-ai/dsh-session-format-catalog`。在源码目录安装开发依赖后即可使用。校验器缺失或回放失败时，工具会报告原因并保留原文件。
